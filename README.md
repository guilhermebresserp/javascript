# javascript

## PORTUGUÊS / PORTUGUESE

Curso de JavaScript do CursoemVideo.

Abordado no curso desde conceitos básicos até recursos modernos. Começando com a criação dos primeiros scripts até o uso de funções e manipulação de elementos do DOM, base essencial para construir páginas interativas e dinâmicas.

O conteúdo segue as normas do ECMAScript, a especificação oficial da linguagem, garantindo que o aprendizado esteja alinhado com as práticas mais atuais do mercado.

### Módulo A: Conhecendo o JavaScript
* **História e Evolução:** Como o JavaScript surgiu, a relação com a Web e o padrão ECMAScript.
* **Capacidades da Linguagem:** O que é possível construir com JS no navegador e fora dele.
* **Configuração de Ambiente:** Instalação de editores de código (como o VS Code) e navegadores.
* **Primeiros Scripts:** Execução de comandos simples e criação da primeira interatividade na tela.

### Módulo B: Comandos Básicos do JavaScript
* **Variáveis e Tipos Primitivos:** Declaração de variáveis (`var`, `let`, `const`) e tipos de dados (Numbers, Strings, Booleans).
* **Tratamento de Dados:** Conversão entre tipos (parsing), concatenação de texto e *template strings*.
* **Operadores em JS:**
  * Operadores Aritméticos (`+`, `-`, `*`, `/`, `%`, `**`).
  * Operadores de Atribuição, Relacionais e Lógicos (`&&`, `||`, `!`).
  * Operador Ternário (`condição ? true : false`).

### Módulo C: Entendendo o DOM (Document Object Model)
* **Árvore DOM:** Compreensão de como o JavaScript enxerga e manipula a estrutura HTML/CSS de uma página web.
* **Seleção de Elementos:** Uso de métodos como `getElementById()`, `getElementsByTagName()`, `querySelector()` e `querySelectorAll()`.
* **Eventos DOM:** Captura de interações do usuário (clique, passagem do mouse, entrada de dados em campos) e execução de funções associadas a esses eventos.

### Módulo D: Condições em JavaScript
* **Estruturas Condicionais:** Uso de `if`, `else` e `else if` para controle de fluxo.
* **Condições Múltiplas:** Uso do `switch / case`.
* **Prática Guiada:** Exercícios práticos envolvendo verificação de idade, horários do dia e condições climáticas dinâmicas com alteração de interface.

### Módulo E: Repetições em JavaScript
* **Estruturas de Repetição (Laços):** Funcionamento de `while`, `do ... while` e `for`.
* **Controle de Fluxo:** Utilização de incrementos e contadores para repetição de código.
* **Prática Guiada:** Resolução de problemas reais (como criação de geradores de tabuada e contadores interativos).

### Módulo F: Avançando os Estudos em JavaScript
* **Variáveis Compostas (Arrays/Vetores):** Criação, manipulação e busca em listas/vetores (`push()`, `length`, `indexOf()`, laço `for...in`).
* **Funções:** Conceito de rotinas, parâmetros, retorno de valores e escopo de variáveis.
* **Introdução a Objetos:** Conceitos iniciais de estruturas de objetos simples em JS.
* **Orientações:** Para onde seguir após dominar a base (frameworks, Node.js, JS assíncrono, etc.).

## INGLÊS / ENGLISH

JavaScript Course by CursoemVideo.

Covering concepts from basics to modern features. Starting with creating your first scripts up to using functions and manipulating DOM elements—the essential foundation for building interactive and dynamic web pages.

The content follows ECMAScript standards, the official specification of the language, ensuring that learning is aligned with current market practices.

### Module A: Getting to Know JavaScript
* **History and Evolution:** How JavaScript emerged, its relationship with the Web, and the ECMAScript standard.
* **Language Capabilities:** What can be built with JS inside and outside the browser.
* **Environment Setup:** Installing code editors (such as VS Code) and browsers.
* **First Scripts:** Executing simple commands and creating your first on-screen interactivity.

### Module B: Basic JavaScript Commands
* **Variables and Primitive Types:** Variable declarations (`var`, `let`, `const`) and data types (Numbers, Strings, Booleans).
* **Data Handling:** Type conversion (parsing), text concatenation, and template strings.
* **JS Operators:**
  * Arithmetic Operators (`+`, `-`, `*`, `/`, `%`, `**`).
  * Assignment, Relational, and Logical Operators (`&&`, `||`, `!`).
  * Ternary Operator (`condition ? true : false`).

### Module C: Understanding the DOM (Document Object Model)
* **DOM Tree:** Understanding how JavaScript sees and manipulates the HTML/CSS structure of a web page.
* **Element Selection:** Using methods like `getElementById()`, `getElementsByTagName()`, `querySelector()`, and `querySelectorAll()`.
* **DOM Events:** Capturing user interactions (clicks, mouse hover, field data input) and executing functions associated with these events.

### Module D: Conditions in JavaScript
* **Conditional Statements:** Using `if`, `else`, and `else if` for flow control.
* **Multiple Conditions:** Using `switch / case`.
* **Guided Practice:** Practical exercises involving age verification, time of day, and dynamic weather conditions with interface modifications.

### Module E: Loops in JavaScript
* **Repetition Structures (Loops):** How `while`, `do ... while`, and `for` work.
* **Flow Control:** Using increments and counters to repeat code.
* **Guided Practice:** Solving real-world problems (such as creating multiplication table generators and interactive counters).

### Module F: Advancing Your JavaScript Studies
* **Composite Variables (Arrays):** Creating, manipulating, and searching lists/arrays (`push()`, `length`, `indexOf()`, `for...in` loop).
* **Functions:** Concepts of routines, parameters, return values, and variable scope.
* **Introduction to Objects:** Initial concepts of simple object structures in JS.
* **Guidance:** On where to go after mastering the basics (frameworks, Node.js, asynchronous JS, etc.).
